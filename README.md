# Bow Arkwright

Independent full-stack developer. I build small, strange, useful things — browser labs, local-first tools, song studies, and the occasional poem generator.

[🌐 Site & dev log](https://saddledove.github.io) · [📓 Notes on rock & poetry](https://saddledove.github.io/saddle-notes/)

## Projects

| Project | What it is | Stack |
|---|---|---|
| [AcousticRealms](https://github.com/SaddleDove/AcousticRealms) | In-browser bioacoustics AI lab — train a CNN on humpback whale song & birdsong, then ID what you record with your mic | Next.js · TF.js |
| [alphalab](https://github.com/SaddleDove/alphalab) | Agent-based market simulator, auction-theory lab & sports-betting research | TypeScript |
| [papernest](https://github.com/SaddleDove/papernest) | Local-first, self-hosted reading workbench for AI papers | React |
| [podforge](https://github.com/SaddleDove/podforge) | AI podcast generator — turn any content into natural dual-host audio | TypeScript |
| [auralis](https://github.com/SaddleDove/auralis) | AI editing workstation — edit audio & video by editing text | TypeScript |
| [modern-divina-commedia](https://github.com/SaddleDove/modern-divina-commedia) | A digital-age retelling of Dante — inferno as the feed, purgatory as the queue | HTML |
| [close-reading](https://github.com/SaddleDove/close-reading) | Song lyrics under a microscope — rhyme, meter & refrain, set to notation | TypeScript |
| [zine](https://github.com/SaddleDove/zine) | Turn a folder of markdown into a printable zine | Python |
| [poem](https://github.com/SaddleDove/poem) | A poem generator that knows exactly three words | Python |
| [deploy-watcher](https://github.com/SaddleDove/deploy-watcher) | Run a command, get the right song for the result | Python |
